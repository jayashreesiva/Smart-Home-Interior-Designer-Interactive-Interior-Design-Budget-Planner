# 🏠 Smart Home Interior Designer

## 📌 Project Overview

**Smart Home Interior Designer** is a modern and interactive web application designed to help users explore home interior ideas, discover furniture, customize room preferences, and estimate their interior design budget.

The application provides an attractive digital platform for users to explore different interior styles such as **Modern, Minimal, Luxury, Scandinavian, Traditional, and Contemporary**.

The main purpose of this project is to demonstrate **Web Technology concepts, responsive UI/UX design, JavaScript interactivity, form handling, filtering, and dynamic calculations** through a real-world application.

---

## 🎯 Objectives

* Create a modern and visually attractive interior design website.
* Allow users to explore different room designs.
* Provide room-wise interior inspiration.
* Allow users to filter designs based on style.
* Provide furniture information and pricing.
* Calculate an approximate interior design budget.
* Provide designer profiles and consultation options.
* Create a responsive website for desktop, tablet, and mobile.
* Demonstrate practical Web Technology concepts.

### 🏠 Home Page

* Modern landing page
* Attractive hero section
* Interior design images
* Call-to-action buttons
* Featured designs

### 🛋️ Room Designs

Users can explore designs for:

### 🎨 Design Styles

Users can explore different interior styles:

* Modern
* Minimal
* Luxury
* Scandinavian
* Traditional
* Contemporary

A filtering system allows users to find designs based on their preferred style.

### 🪑 Furniture Collection

The furniture section displays:

* Furniture image
* Product name
* Category
* Price
* Rating
* View Details button

Example categories include:

* Sofa
* Bed
* Dining Table
* Wardrobe
* Study Table
* Coffee Table

### 💰 Budget Planner

The Budget Planner allows users to estimate their interior design cost.

Users can select:

* Room type
* Room size
* Design style
* Furniture requirements
* Material type

The application then calculates an approximate budget using JavaScript.

The website contains professional designer profiles with:

* Designer photograph
* Name

* Rating
* Book Consultation button

### 🖼️ Interior Gallery

A beautiful image gallery allows users to explore different interior designs.

* Image cards

* Hover effects
* Full-size image viewing
* Responsive gallery layout
